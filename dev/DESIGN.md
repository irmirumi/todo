# 또박·끄적 디자인 시스템 (3.1.0~)

`dev/src/style.css`는 이 문서의 순서대로 짜여 있다. 새 화면·요소를 만들 때 **값을 새로 만들지 말고 아래 토큰과 부품을 쓴다.**
토큰에 없는 값이 꼭 필요하면 여기에 먼저 더하고 이유를 적는다. 버전별로 아래에 덧붙이지 않는다(2.x까지 그렇게 해서 누더기가 됐다).

## 0. 원칙(사용자 취향, HANDOFF 2장·6장에서)

- 무채색 바탕(따뜻한 회색), 색은 의미가 있을 때만: 강조색(또박 핑크·끄적 청록)은 '오늘'과 주요 버튼, 카테고리 색은 체크·태그·형광펜·칸·메모 바탕.
- **둥근 사각형의 한쪽 면에만 선을 넣지 않는다.** 구분선은 둥글지 않은 요소나 `::before` 직선으로.
- 크기가 다른 글자를 한 줄에 둘 때는 baseline. 여러 줄 묶음 옆의 이름은 그 묶음 가운데.
- 폰에서 여백을 줄이지 않는다(글자만 한 단계). 누르는 곳은 40px 이상(`::after`로 넓힘), 입력칸 글자 16px 이상.
- 움직임은 짧게, 늘 위치 변화와 같이. 페이드만 하는 연출 금지.
- **앱 이름을 화면 위에 제목처럼 쓰지 않는다**(사용자 지적, 3.0.0에 끄적 머리에 '끄적'을 써서 다시 지적받음). 머리에는 그 화면에서 할 일(검색·탭·버튼)만.

## 3. 화면 묶음

style.css 차례: 토큰 → 바탕 → 틀(머리·탭·배치) → 부품 → 달력 → 하루 → 전체 → 시간표 → 시트·창 → 로그인 → 알림 → 메모(보기·보드·시트) → 끄적(폰) → 서식 편집기 → 움직임 → 터치·움직임 줄이기.
폰(560px 이하) 값은 각 묶음 끝의 `@media` 한 곳에 둔다.
