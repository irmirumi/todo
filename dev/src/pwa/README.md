- `server/worker.js`: 알림 서버 코드(Cloudflare에 붙여넣는 것)
- `dev/`: 앱의 원본 코드와 빌드 스크립트. `python3 dev/build.py` → `dev/dist/app`을 맨 위로 복사(`firebase-config.js`는 빼고)

# 처음 설치하는 법

폰 홈 화면 아이콘으로 바로 열리는 할 일 앱을 무료로 직접 띄우는 방법이야. 개발 지식 없이 웹사이트 클릭만으로 할 수 있고, PC에서 하는 게 편해. 처음 한 번 20분쯤 걸려.

- **Firebase**(구글): 로그인이랑 할 일 저장을 맡아. 무료 요금제로 충분해.
- **GitHub Pages**: 앱 파일을 올려두는 무료 호스팅이야.

준비물은 Google 계정과 GitHub 계정(없으면 github.com에서 가입)이야.

---

## 1. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 들어가서 **프로젝트 만들기**를 눌러.
2. 이름은 아무거나 괜찮아(예: `my-todo`). Google 애널리틱스는 **사용 안 함**으로 해도 돼.

## 2. 웹 앱 등록하고 설정값 붙여넣기

1. 프로젝트 첫 화면에서 **웹 아이콘 `</>`**을 눌러.
2. 앱 닉네임을 적어(예: `todo`). **Firebase 호스팅 설정은 체크하지 마.**
3. 화면에 `const firebaseConfig = { apiKey: "...", ... };` 형태의 코드가 나와. 중괄호 `{ }` 안의 내용을 복사해.
4. 이 폴더의 **`firebase-config.js`**를 메모장으로 열고, `{ }` 안을 복사한 내용으로 바꿔서 저장해. 결과는 이런 모양이어야 해.

```js
export const firebaseConfig = {
  apiKey: "AIza....",
  authDomain: "my-todo-xxxx.firebaseapp.com",
  projectId: "my-todo-xxxx",
  storageBucket: "my-todo-xxxx.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcd..."
};
```

> 이 값은 공개돼도 괜찮은 값이야. 실제 보안은 4단계의 규칙이 맡아.

## 3. 로그인 켜고 내 계정 만들기

1. 왼쪽 메뉴에서 **빌드 → Authentication → 시작하기**로 들어가.
2. **로그인 방법** 탭에서 **이메일/비밀번호**를 사용 설정하고 저장해. 이메일 링크는 꺼둬도 돼.
3. **Users** 탭에서 **사용자 추가**를 누르고, 앱에서 쓸 이메일과 비밀번호를 정해.
4. (권장) **설정 → 사용자 작업**에서 **생성(가입) 사용** 체크를 해제해. 이렇게 하면 다른 사람이 네 Firebase에 계정을 만들 수 없어.

## 4. 저장소(Firestore) 만들고 보안 규칙 넣기

1. 왼쪽 메뉴에서 **빌드 → Firestore Database → 데이터베이스 만들기**로 들어가.
2. 위치는 **asia-northeast3 (서울)**을 골라. 위치는 나중에 바꿀 수 없어.
3. **프로덕션 모드**로 시작해.
4. 만들어지면 **규칙** 탭을 열고, 기존 내용을 지운 뒤 이 폴더의 **`firestore.rules`** 내용을 붙여넣고 **게시**해.
   이 규칙은 "로그인한 본인만 자기 할 일을 읽고 쓸 수 있다"는 뜻이야.

## 5. GitHub에 파일 올리기

1. https://github.com/new 에서 저장소를 만들어. 이름은 예를 들어 `todo`로 하고, **Public**으로 둬. 무료 계정은 Public이어야 Pages를 쓸 수 있어. 공개돼도 할 일 내용은 Firebase에 있어서 남이 볼 수 없어.
2. 만든 저장소 화면에서 **uploading an existing file** 링크를 눌러.
3. 이 폴더 안의 **파일과 `icons` 폴더를 전부** 드래그해서 올려. 폴더 자체가 아니라 그 안의 내용물이야. `index.html`이 저장소 맨 위에 있어야 해.
   - `.nojekyll`처럼 점으로 시작하는 파일은 안 보일 수 있는데, 빠져도 동작해.
4. 아래 **Commit changes**를 눌러.

## 6. GitHub Pages 켜기

1. 저장소의 **Settings → Pages**로 들어가.
2. **Source: Deploy from a branch**, **Branch: `main` / `(root)`**를 고르고 **Save**를 눌러.
3. 1~2분 뒤 같은 화면 위쪽에 주소가 떠. 예: `https://내아이디.github.io/todo/`

PC에서 그 주소를 열고, 3단계에서 만든 이메일과 비밀번호로 로그인되는지 확인해.

## 7. 폰 홈 화면에 앱으로 추가

- **안드로이드(크롬)**: 주소를 열고 로그인 → 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰(사파리)**: 주소를 열고 → 아래 공유 버튼 → **홈 화면에 추가**
  - 아이폰은 홈 화면 앱이 사파리와 로그인을 따로 기억해서, 아이콘으로 처음 열 때 한 번 더 로그인해야 해.

이제 아이콘을 누르면 주소창 없이 앱처럼 열려. 로그인은 계속 유지돼.

## 8. 기존 할 일 옮기기

1. 지금 쓰던 Claude 또박에서 **⋯ → 데이터 내보내기 → 복사**를 눌러.
2. 새 앱에서 **⋯ → 데이터 가져오기**를 열고, 붙여넣은 다음 **확인 → 가져오기**를 눌러.

카테고리, 소분류, 할 일이 그대로 넘어와. 같은 데이터를 두 번 가져와도 중복되지 않아.

## 알아두면 좋은 것

- **오프라인**: 인터넷이 없어도 열리고, 체크하거나 추가한 건 연결되면 자동으로 올라가.
- **고친 버전 올리기**: Claude에게 저장소를 연결해 두면 Claude가 직접 올려. 손으로 올릴 땐 바뀐 파일만 저장소의 Add file → Upload files로 덮어쓰면 되고, `firebase-config.js`는 네 값이 든 걸 그대로 둬야 해.
- **"설정이 남았어요" 화면이 나오면**: `firebase-config.js`가 원래 내용 그대로 올라간 거야. 2단계를 다시 확인해.
- **"이메일이나 비밀번호가 맞지 않아요"**: Authentication → Users에 그 이메일이 있는지 확인해. 비밀번호를 잊었으면 거기서 사용자를 지우고 다시 만들면 돼. 할 일 데이터는 사용자 ID에 묶여 있으니까, 다시 만들기 전에 꼭 내보내기를 해둬.
- **비용**: 혼자 쓰는 할 일 앱은 Firebase 무료 한도에 한참 못 미쳐. 카드 등록도 필요 없어.

## 알림 서버 (선택, 무료)

할 일마다 "몇 분 전" 알림을 받으려면 Cloudflare 무료 플랜에 알림 서버를 하나 둔다. 카드 등록이 없어서 요금이 나갈 수 없다.
코드는 이 저장소의 `server/worker.js` 한 파일이고, Cloudflare Worker 편집기에 그대로 붙여넣는다.
필요한 연결은 두 가지: D1 데이터베이스(변수 이름 `DB`), 크론 트리거 `* * * * *`(매분).
서버 주소는 `reminder-config.js`에 들어간다. 비어 있으면 알림 기능이 화면에 나오지 않는다.
